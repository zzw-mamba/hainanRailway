# 海南路链上下行标注依据

此版本为派生推断，不是源 OSM 的原生属性，也不是业务接口 `direction=UP/DOWN` 的下载结果。网页、列表及筛选均明确显示“上行（推断）/下行（推断）”。源路链 GeoJSON 不修改。

## 可核对的方向基准

海南交通集团的公开记录将 `G98 K294+038（三亚往乐东方向）` 称为“上行”：
https://www.hainanjk.com/wx/NewsList.aspx?Page=76&cId=23&tx=

这是本文使用的上下行校准点。三亚经西南侧主线往乐东的方向，与 G98 环线顺时针行车方向一致。因此仅对 G98 的连续主线推断：顺时针为上行，逆时针为下行。

OSM 的 `forward/backward` 是相对于 Way 坐标顺序的通行角色，不能直接翻译为上行/下行：
https://wiki.openstreetmap.org/wiki/Relation:route

## 本地数据验证

从现有 `data/pbf/hainan-260922.osm.pbf` 提取 road route relations。G98 的 OSM relation ID 为 `909075`，包含 928 个 Way 成员。通过 Way ID 与拆分输出关联后，保留主线及明确单向通行的路链。

以 7 位小数经纬度匹配端点，形成两个互不相连的连续主线组件。检查每个组件没有分叉，且各节点最多一条入边、一条出边。汇总绕参考点 `(109.7, 19.15)` 的连续角度变化，约为 `+6.2634` 和 `-6.2627` 弧度，接近两个方向各一整圈。只有同时存在两个方向相反、无分叉、近乎完整环线的组件，才接受推断；否则全部退回待确认。

采用整条主线的拓扑传播，而不是单段经纬度增减：局部弯道不会自行改变上下行标签。`oneway=-1` 会反转坐标后再计算实际通行方向。

当前结果：

| 标注 | 路链数 |
| --- | ---: |
| 上行（推断） | 1,671 |
| 下行（推断） | 1,676 |
| 上下行待确认 | 7,254 |
| 双向（上下行未区分） | 79 |

G98 路线关系范围与仅按 `ref=G98` 筛选的范围并不完全相同：标签遗漏、联络路段等可能导致差异。成员身份使用原始 Way ID，未按路名或地理位置随意扩大标注范围。

## 其他路线

原始 PBF 还存在“沈海高速（海口方向）”“兰海高速（兰州方向）”“疏港高速（进港方向）”等路线关系。将这些信息展示为 OSM 路线方向提示，保持来源语义；没有当地上下行定义时，不转换为 UP/DOWN。

匝道未沿用邻近主线标签，因为需要明确出入口、接入主线及行车路径。未核对其他路线的上下行基准前，也不应用 G98 的环线规则。

后续若取得业务方向或里程桩号数据，应先按空间位置、道路身份及实际通行方向匹配，再复核或替换推断，保留原始方向字段和本次推断来源。
